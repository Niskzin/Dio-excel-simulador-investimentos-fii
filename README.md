# Simulador de Investimentos em Fundos Imobiliários

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de aplicar conhecimentos de Excel na criação de uma ferramenta prática para simulação de investimentos em Fundos Imobiliários (FIIs).

A ferramenta permite realizar simulações considerando diferentes valores de aporte, períodos de investimento e taxas de rendimento.

## Objetivo

O objetivo do projeto é facilitar a visualização do crescimento de um investimento ao longo do tempo, permitindo ao usuário analisar diferentes cenários e estimar possíveis dividendos mensais.

## Funcionalidades

* Definição do salário do investidor;
* Sugestão de valor para investimento mensal;
* Definição do aporte mensal;
* Definição do período de investimento;
* Definição da taxa de rendimento mensal;
* Cálculo do patrimônio acumulado;
* Estimativa de dividendos mensais;
* Simulação de diferentes períodos de investimento;
* Comparação de cenários de 2, 5, 10, 20 e 30 anos;
* Gráfico para visualização do patrimônio estimado;
* Seleção de perfil de investidor;
* Sugestão de distribuição entre diferentes tipos de FIIs.

## Perfis de investimento

A ferramenta considera três perfis:

* **Conservador**
* **Moderado**
* **Agressivo**

Cada perfil possui uma sugestão diferente de distribuição entre tipos de Fundos Imobiliários.

## Tipos de FIIs considerados

* Papel
* Tijolo
* Híbridos
* FOFs
* Desenvolvimento
* Hotelarias

## Tecnologias utilizadas

* Microsoft Excel
* Fórmulas do Excel
* Tabelas e organização de dados
* Formatação condicional
* Gráficos
* GitHub
* Markdown

## Como utilizar

1. Baixe o arquivo Excel disponível neste repositório.
2. Abra a aba **APP**.
3. Informe o salário, aporte mensal, período e taxa de rendimento.
4. Analise o patrimônio acumulado e os dividendos estimados.
5. Explore os diferentes cenários apresentados.
6. Utilize a aba **Planilha2** para visualizar as sugestões de distribuição por perfil.

## Resultados

A ferramenta permite visualizar de forma simples o impacto dos aportes e do tempo sobre o patrimônio acumulado, além de apresentar uma estimativa dos dividendos mensais.

## Observação

Este projeto possui finalidade educacional. Os resultados apresentados são baseados nos valores e taxas informados pelo usuário e representam apenas simulações, não constituindo garantia de rentabilidade futura.
